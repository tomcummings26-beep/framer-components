# Framer Components

Framer code components synced via the [GitHub Link plugin](https://www.framer.com/marketplace/plugins/github-link/).

## Structure

```
main-components/   # Core page components (PDP, PLP, Hero, Footer, etc.)
seo-components/    # SEO block components by region and type
```

## Workflow

1. Edit components in Framer's code editor
2. Open the GitHub Link plugin
3. Push changes to this repo
4. Pull updates back into Framer when needed
